# Stock Car Empire

1988 chairman’s office for United Stock Car Racing.

A team plugs in a fictional sponsor. The late-80s car — Monte Carlo SS, Thunderbird, Grand Prix, Regal, or Cutlass — is produced from that business’s colors and wordmark. J. W. Wyatt approves the car or sends it back. One sponsor name cannot sit on two cars.

## Run

```bash
npm install
npm run dev
```

The desk opens on port 8080.

This is the browser app, not the older Python career book. The name USCRA was already taken on this account and was not readable from here, so the code lives in this repository.
