# Stock Car Empire

1988 chairman’s office for **United Stock Car Racing Association (USCRA)**. The premier championship remains the **United Racing Cup (URC)**, and the second-tier championship remains the **National Racing Circuit (NRC)**.

A team plugs in a fictional sponsor. The late-80s car — Monte Carlo SS, Thunderbird, Grand Prix, Regal, or Cutlass — is produced from that business’s colors and wordmark. J. W. Wyatt approves the car or sends it back. One sponsor name cannot sit on two cars.

## Run

```bash
npm install
npm run dev
```

The desk opens on port 8080.

This is the separate browser-app scaffold, not the Python SQLite career runtime in [garrettmbf-sudo/USCRA](https://github.com/garrettmbf-sudo/USCRA). Both projects use the approved USCRA display identity. The Python save system deliberately keeps its legacy governing-body database key `GOV_USCR` so existing worlds remain compatible.
